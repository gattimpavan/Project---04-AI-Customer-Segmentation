1. Problem Formulation & Theoretical Background

Spotify operates in a hyper-competitive audio streaming environment where traditional demographic segmentation (age, gender, geographical country) acts as a severe bottleneck. Two 24-year-old users in the same zip code can have entirely divergent acoustic mindsets: one is a deep-work ambient focus streamer listening 5 hours a day on desktop DAC headphones, while another is a casual commuter with an 80% skip rate and high churn propensity. Targeting both with identical generic push notifications produces high unsubscribe rates, inflated CAC, and low trial conversion.

2. Unsupervised Machine Learning Pipeline

Our machine learning architecture leverages an 18-dimensional feature vector spanning streaming duration, dayparts, skip rates, acoustic properties (danceability, energy, valence, acousticness, instrumentalness), content diversity (podcast and audiobook hours), and transactional indicators. Heavy-tailed count features are log-transformed, normalized via StandardScaler, and projected into a 2D/3D latent space via Principal Component Analysis (PCA). We employ both K-Means++ for hard partition centroid discovery and Gaussian Mixture Models (GMM) with full covariance matrices to calculate probabilistic soft cluster membership.

3. LLM Customer Intelligence Architecture

Rather than presenting mathematical centroids directly to non-technical marketing directors, our LLM engine translates statistical Z-score vectors into vivid psychological personas. It synthesizes listening mindsets, identifies cognitive friction points, and recommends differentiated marketing strategies across 5 core tactical pillars: Value Proposition, Omnichannel Copy (Push, In-App, Email, Audio Ads), Retention Guardrails, Monetization Pathways, and Algorithmic Curation.
